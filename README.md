# Associação Clube da Família — novo site

Site institucional da Associação Clube da Família (Votorantim/SP), desenvolvido pela Benne Comunica.
Versão para aprovação do cliente.

## Páginas
- `index.html` — Início (apresentação + Sobre nós)
- `projetos.html` — Projetos + Galeria de fotos
- `faca-parte.html` — Doações, voluntariado e contato

## Estrutura
- `assets/site.css` — estilos compartilhados
- `assets/site.js` — menu mobile, contador, galeria com lightbox, copiar PIX e formulário
- `assets/img/` — logo, fotos, ícones ODS e QR Code PIX

## Publicar no GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch `main` / pasta `/ (root)` → Save.

## Pendências para a versão final
- Ligar o formulário de contato a um serviço de envio (hoje ele só mostra a confirmação na tela).
- Incorporar o mapa do Google na página Faça parte.
- Trocar o ícone do botão de WhatsApp pelo ícone oficial do kit de marca do WhatsApp, se desejado.
